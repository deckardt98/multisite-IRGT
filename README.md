# multisite-IRGT

This repository implements the methods in “[Designing multicenter individually randomized group treatment trials](https://doi.org/10.1002/bimj.202200307)” by Guangyu Tong, Jiaqi Tong, and Fan Li, published in *Biometrical Journal* (2024). It contains R scripts for the paper's simulations, numerical illustrations, and trial examples, generating the tables and figure listed below.

## Repository contents

| Script | Output |
| --- | --- |
| [`simulation set 1 code.R`](simulation%20set%201%20code.R) | Table 2 and Web Tables 1–5. |
| [`simulation set 2 code.R`](simulation%20set%202%20code.R) | Table 3. |
| [`FIGURE 2 PLOT CODE.R`](FIGURE%202%20PLOT%20CODE.R) | Figure 2. |
| [`STPD CODE.R`](STPD%20CODE.R) | Table 4. |
| [`CODA CODE.R`](CODA%20CODE.R) | Table 5. |

In the simulation scripts, each iteration section corresponds to one column of the relevant table.
